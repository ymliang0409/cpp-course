5.1

while 敘述

只要條件式為真，就會重複執行大括號裡的敘述。每一輪開始前都先檢查條件。

while (條件式) {
    程式敘述;
    …
}
必須小心設定條件式。若迴圈裡沒有讓條件變成 false 的動作，就會變成無窮迴圈。勾選下面的選項試試看。

用 while 不斷讀入測資

cin >> a >> b 讀取成功時視為 true，所以可以一直讀，直到輸入結束（Windows 按 Ctrl + Z）。

while (cin >> a >> b) {
    cout << a + b << endl;
}

5.3
continue 與 break

  

    

      
continue：略過這一輪剩下的程式碼，直接跳到下一輪的起始位置（回到條件判斷）。

      

    

    

      
break：與 continue 相反，遇到 break 就直接跳出整個迴圈。常搭配 while (1) 使用。

      

    

  







  
5.4
for 敘述

  

    

      
C/C++ 用來處理重複事件的語法稱為迴圈敘述。for 把迴圈的三個要素寫在同一行：


for (①起始值; ②條件式; ③遞增或遞減運算) {
    程式敘述句1;
    程式敘述句2;
}

      
執行順序：

      
    
        
  1. 1 設定變數的起始值（只做一次）
    2. 
        
  2. 2 判斷條件式，true 就執行下方程式區塊，false 就結束
    3. 
        
  3. 執行完區塊後做 3 遞增或遞減，再回到 2
    4. 
      

      
右邊追蹤時，黃色標示正在執行 for 的哪一段。

5.5
巢狀迴圈

  

    

      
迴圈裡面還有其他迴圈就叫做巢狀迴圈，for 或 while 都可以形成巢狀迴圈。

      
外圍的迴圈每執行一次，內側的迴圈就要完整跑完一輪。右邊外圈 3 次 × 內圈 3 次，共印出 9 行。


for (式子1-1; 式子2-1; 式子3-1) {
    …
    for (式子1-2; 式子2-2; 式子3-2) {
        …
    }
}

    

    

  


  

    

      
搭配 if 敘述

      
巢狀迴圈可以搭配其他敘述使用。這個例子用變數 ch 在 0、1 之間切換，交錯印出 * 與 _。

      
注意：ch 在換行時不會重設，所以第 2 列從 _ 開始，排出棋盤格。播放時可以拖曳進度條快轉。

    

    

  


  

    

      

        
想一想：下面的程式做的事為何？


for (i = 1; i <= 5; i++) {
    for (j = 1; j <= 3; j++) {
        for (k = 1; k <= 10; k++) {
            cout << "*";
        }
        cout << endl;
    }
    cout << endl;
}

        
      

      

        
三層迴圈：最內層 k 印 10 個 *，中層 j 印 3 行後空一行，外層 i 重複 5 組。共 5 × 3 × 10 = 150 個星號。
