第二章 變數與常數

深入瞭解記憶體概念、資料型態、變數命名規則、常數宣告以及基本輸入輸出（cin / cout）操作。

什麼是變數 (Variable)？

基本概念

變數是程式語言中最基本的元素之一。

存放位置

變數通常是存放在電腦的記憶體 (Memory) 空間內，就像一個用來儲存資料的「盒子」。

記憶體與變數對照示意圖
記憶體位址
📦 變數 (Variable Box)

變數宣告方式

宣告語法格式：
type var-name;

1. type（資料型態）

  • • int：整數
  • • float：小數（浮點數）
  • • char：字元
  • • bool：布林值 (true/false)

2. var-name（變數名稱）

自行設定的識別字名稱，用於代表該變數以供後續程式存取與修改。

建立變數名稱規則

可以使用英文字母、阿拉伯數字、底線（_）、$ 等符號作為名稱，無法包含其他特殊符號。
視環境而定，名稱最長不得超過 255 個字元。
保留起來的關鍵字 (keyword) 不能做為名稱（常見如：return, int, for...）。
名稱不能用阿拉伯數字作為開頭（例如 1num 不合法）。
英文字母的大小寫有區別（例如 Num 與 num 代表不同變數）。

資料型態、記憶體與範圍

類型 型態 佔用記憶體 可儲存數值範圍
布林bool1 位元組0 ~ 255 (true / false)
整數short2 位元組-215 ~ 215-1
int4 位元組-231 ~ 231-1
long long8 位元組-263 ~ 263-1
小數float4 位元組精確位數 7~8 位
double8 位元組精確位數 16~17 位
字元char1 位元組0 ~ 255 (ASCII)

變數初始化與賦值

注意：等號 (=) 的意思並非數學上的「等於」，而是將右方的數值「指定給 (Assign)」左方的變數。
// 整數型態
int num1 = 3;

// 浮點數型態
float num2 = 3.14;

// 布林變數
bool check = true; (1亦可, 0表false)
// 字元型態 (使用單引號)
char ch = 'A';

// 亦可指定 ASCII 碼 (A的ASCII為65)
char ch = 65;

// 錯誤示範: char ch = "A";
// 若使用雙引號需改為 string ch = "A";

常數與前置處理器

常數 (const)

執行期間數值不可被重新指定或改變。

const int num = 35;

前置處理器 (#define)

替換常數或字串為自訂識別名稱，在編譯前直接替換。

#define PI 3.14159
(注意：末端不需要加分號)

輸出基本操作 (cout)

cout << 運算式1 << 運算式2 << ... << 運算式n;
使用 << (串流插入運算子) 可將多個字串、變數或算式串接輸出。
cout << "num1 = " << num1 << endl;
cout << num1 + num2 << endl; // 加法
cout << num1 - num2 << endl; // 減法
cout << num1 * num2 << endl; // 乘法
cout << num1 / num2 << endl; // 除法

跳脫字元 (Escape Characters)

\a : 警告音
\b : BackSpace
\t : 水平 tab
\v : 垂直 tab
\n : 換行
\f : 換頁
\r : Return
\\ : 反斜線 \
\' : 單引號 '
\" : 雙引號 "
\? : 問號 ?
\000 : 8進制碼

浮點數的輸出位數控制

1. 需引入 #include <iomanip> 標頭檔。
2. 使用 setprecision(int i) 控制輸出位數。
3. 若要只控制小數點以下的位數，再加上 fixed 格式控制。
cout << fixed << setprecision(2) << 3.14159;
// 輸出結果：3.14

改變變數的值

num1 = 3;
cout << "變數num1的值是" << num1 << endl;

num1 = 5;
cout << "變數num1更新後的值是" << num1 << endl;
執行結果：
變數num1的值是3。
變數num1更新後的值是5。

當賦予變數新數值時，舊有記憶體中的數值會被直接覆蓋。

輸入基本操作 (cin)

cin 輸入語法格式：
cin >> 運算式1 >> 運算式2 >> ... >> 運算式n;

使用 >> (串流擷取運算子) 可以從鍵盤讀取使用者輸入的值，並依序儲存至指定變數中。

cin >> num1 >> num2;
