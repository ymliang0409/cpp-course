2.1

變數與記憶體

變數是程式語言最基本的元素之一，通常存放在記憶體（memory）內。

可以把變數想成記憶體裡的一個盒子：宣告變數時，程式會在記憶體中切出一塊空間，貼上名字，之後就能把資料放進去、拿出來。

type var-name;

  • type：變數的資料型態，例如 int（整數）、float（小數）、char（字元）、bool（布林值）。
  • var-name：變數名稱。

2.2

資料型態

型態決定變數佔多少記憶體，也決定能存多大的數。1 位元組（Byte）= 8 位元（bit），n 位元可以表示 2n 種不同的值。

放得下嗎？

補充：投影片把 bool 的範圍寫成 0～255，bool 雖然佔 1 Byte，實際上只存 true 或 false。char 在多數編譯器上是 -128～127；要 0～255 需寫成 unsigned char。

2.3

變數名稱的規則

  • 使用英文字母、阿拉伯數字、底線（_）等符號作為識別字名稱，不能包含其他特殊符號（空白、-、#、@…）。
  • 視環境而定，最長不得超過 255 個字元。
  • 保留起來的關鍵字（keyword）不能作為識別字名稱，例如 return、int、for。
  • 識別字名稱不能用阿拉伯數字開頭。
  • 英文字母的大小寫有區別：Score 和 score 是兩個不同的變數。

投影片提到 $：GCC 等編譯器接受 $ 當作名稱的一部分，但它不是 C++ 標準，考試與正式程式都建議不要使用。

2.4

變數初始化

宣告時順便給初始值，叫做初始化。

等號（=）的意思並不是「等於」，而是「指定給」：把右邊的值放進左邊的變數。

int num1 = 3;          // 整數
float num2 = 3.14;     // 浮點數（小數）
char ch = 'A';         // 字元：用單引號
char ch2 = 65;         // 字母 A 的 ASCII 碼是 65
bool check = true;     // 布林值：true 也可寫 1，false 寫 0

char ch = "A"; 是錯的：雙引號是字串，char 只能放一個字元。要存字串請宣告 string ch = "A";（需要 #include <string>）。

字元與 ASCII 碼

電腦裡的字元其實是一個數字。點表格裡的字元，或直接輸入：

常數與前置處理器

常數：執行時不可被指定或改變。宣告時在前面加上 const，而且必須同時給值。
