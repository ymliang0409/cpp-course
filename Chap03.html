第三章 運算式和運算子

運算式是程式處理計算與邏輯判斷的核心。本章將探討算術、關係、邏輯與位元運算子，並深入介紹優先權、結合性以及型態轉換觀念。

核心觀念解構
sum = sum + i;
運算元 (Operand)
sum, i
運算子 (Operator)
=, +
敘述 (Statement)
加上末尾分號 ;

運算子的分類與結合性

依運算元個數分類

  • 一元運算子 (Unary)： 需要 1 個運算元
    x = -1; // 正負號、遞增遞減 ++ / --
  • 二元運算子 (Binary)： 需要 2 個運算元
    x = y + z; // 加減乘除、比較、邏輯
  • 三元運算子 (Ternary)： 需要 3 個運算元
    max = (x > y) ? x : y; // 唯一的三元運算子

運算子的結合性 (Associativity)

當連續多個「同優先權」的運算子出現時，決定計算順序方向。

左結合性 (Left-to-Right)
a + b + c    (a + b) + c
右結合性 (Right-to-Left)
a = b = 5    a = (b = 5)
指定運算子 = 與單目運算子為典型的右結合性。

算術、複合指定與遞增遞減

算術運算子

+ - * / %

注意：/ 作用於整數時為整數除法（無條件捨去小數）；% 為求餘數。

7 / 2 = 3 (整數除法)
7 % 2 = 1 (取餘數)
複合指定運算子

+= -= *= /= %=

將運算與賦值簡寫，精簡程式碼寫法。

a += b ⇔ a = a + b
a *= 3 ⇔ a = a * 3
遞增 / 遞減

++a vs a++

前置 (Pre) 與後置 (Post) 在運算時機上有細微差別：

b = ++a; // 先加1再給b
b = a++; // 先給b再加1

經典應用：兩變數數值交換 (Swap)

// 方法一：使用暫存變數 temp
int temp = a;
a = b;
b = temp;
// 方法二：加減演算法 (無須第三變數)
a = a + b;
b = a - b;
a = a - b;

關係運算子與邏輯運算子

關係運算子 (Relational)

比較兩數大小，結果為真 (1 / true) 或偽 (0 / false)。

運算子 意義 範例 結果
==等於(2 == 1)false (0)
!=不等於(2 != 1)true (1)
> / <大於 / 小於(2 > 1)true (1)
>= / <=大於等於 / 小於等於(2 <= 1)false (0)

邏輯運算子 (Logical)

用於組合多個條件判斷式。

&& (AND 且)： 兩者皆真才為真
(5 > 3) && (3 > 2) ⇒ true
|| (OR 或)： 任一為真即為真
(5 > 3) || (3 < 2) ⇒ true
! (NOT 反相)： 真偽翻轉
!(5 > 3) ⇒ false

sizeof() 與 型態轉換

資料大小運算子 sizeof()

回傳資料型態或變數在記憶體中所佔用的位元組 (Bytes)。

sizeof(char)  ⇒ 1 Byte
sizeof(bool)  ⇒ 1 Byte
sizeof(int)   ⇒ 4 Bytes
sizeof(float) ⇒ 4 Bytes
sizeof(double)⇒ 8 Bytes

型態轉換 (Type Casting)

1. 自動隱式轉換 (Implicit)

• 提升 (Promotion)：少位元組指定給多位元組（無損）

double m = 2; // m 變為 2.0

• 截斷 (Truncation)：多位元組指定給少位元組（截去小數）

int n = 2.9; // n 截斷為 2
2. 強制顯式轉換 (Explicit) (float)a / b   或   double(a)

手動強制改變運算時的型態以保留精度。

運算子綜合實戰剖析

點擊程式碼各行敘述，觀察變數與運算結果變化：

operators_demo.cpp
int a = 10, b, c, d, e, f;
b = a + 4; // b = 14
c = b - 5; // c = 9
d = 20 - c * 2; // 先乘除後加減
e = a / 4; // 整數除法
f = c % 4; // 取餘數
點擊左側程式碼敘述
點擊左側任何一行運算程式碼，了解算術優先權與運算子計算歷程。
