3.1

運算式與敘述

運算式由運算元和運算子組成。敘述則是在運算式後面加上分號。

  • 運算元：被運算的對象，例如變數 sum、i 或常數 5。
  • 運算子：運算的符號，例如 =、+。

點右邊的按鈕，看各部分是哪些。

3.6

遞增／遞減運算子 ++ --

遞增運算子讓變數的值加 1，下面三種寫法效果相同：

a++;
a = a + 1;
a += 1;

遞減運算子則相反：a--;、a = a - 1;、a -= 1;

延伸：前置與後置

單獨一行時 a++ 和 ++a 一樣。但放在運算式裡就不同了：

  • 後置 b = a++;：先把 a 的舊值給 b，a 再加 1。
  • 前置 b = ++a;：a 先加 1，再把新值給 b。
3.7

逗號運算子 ,

用來分隔敘述，由左而右依序執行。它的運算優先權最低。

常見於宣告多個變數，或 for 迴圈中同時更新兩個變數：for (i = 0, j = 10; i < j; i++, j--)

3.8

關係運算子與邏輯運算子

關係運算子比較兩個運算式的大小關係，條件成立為真（True），不成立為偽（False）。

先想想結果，再點「?」檢查。

邏輯運算子結合多個關係運算式。C++ 通常寫成 &&、||、!，也接受 and、or、not 這種英文寫法。

運算子意義規則
and（&&）且兩邊都 True 才是 True
or（||）或任一邊 True 就是 True
not（!）反相True 變 False，False 變 True

3.9

資料大小運算子 sizeof

sizeof(型態) 或 sizeof(變數) 會得到它佔用的記憶體大小，單位是 Byte（1 Byte = 8 bits）。

cout << "char\t為 "   << sizeof(char)   << " Bytes" << endl
     << "int\t為 "    << sizeof(int)    << " Bytes" << endl
     << "long\t為 "   << sizeof(long)   << " Bytes" << endl
     << "float\t為 "  << sizeof(float)  << " Bytes" << endl
     << "double\t為 " << sizeof(double) << " Bytes" << endl
     << "bool\t為 "   << sizeof(bool)   << " Bytes" << endl;

大小會因編譯器與作業系統而不同。例如 long 在 Windows 是 4 Bytes，在 64 位元的 Linux、macOS 是 8 Bytes。

型態sizeof每格 1 Byte可存的範圍或內容
char1一個字元，如 'A'
int4-2147483648 ～ 2147483647
long4Windows 上與 int 相同
float4小數，約 7 位有效數字
double8小數，約 15 位有效數字
bool1true 或 false
