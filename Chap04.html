流程圖與演算法 (Flowchart & Algorithm)

■ 流程圖 (Flowchart) 表示法

將解決問題的步驟與邏輯，用各種**標準化的符號圖形**來表示。

名稱 圖示/形狀 意義說明
起止符號 圓角矩形/橢圓 表示事件的開始或結束
流程符號 ➔ (箭號) 表示流程進行的方向
輸入/輸出符號 平行四邊形 表示資料的輸出或輸入
處理符號 矩形 表示執行或處理的工作
決策判斷符號 ◇ 菱形 表示對某一條件做判斷

■ 演算法 (Algorithm)

將問題分解成許多小步驟，然後再依一定的次序逐步執行。

演算法五大特性 (Algorithm Features)：

  • 輸入 (Input)： 可有可無 (0 個或多個)。
  • 輸出 (Output)： 產出結果，至少要有一項。
  • 明確性 (Definiteness)： 每個步驟必須明確而清楚。
  • 有限性 (Finiteness)： 必須在有限步驟內完成，不能無限循環。
  • 有效性 (Effectiveness)： 步驟可行，能在一定時間內推算結果。

關係運算子與邏輯運算子 (Relational & Logical Operators)

■ 關係運算子 (用來比較兩運算式大小)

運算子 數學符號 意義 範例 (a=5) 結果
===等於(5 == 3)false (0)
!=≠不等於(5 != 3)true (1)
>>大於(5 > 3)true (1)
<<小於(5 < 3)false (0)
>=≥大於等於(5 >= 5)true (1)
<=≤小於等於(5 <= 3)false (0)
⚠️ 重要提醒： 切勿弄錯 =（指定運算子，將右值賦予左邊）與 ==（關係運算子，比較兩值是否相等）！

■ 邏輯運算子 (判斷複合條件)

! (NOT 反)
&& (AND 且)
|| (OR 或)

真值表 (Truth Table) 互動模擬：

A B !A A && B A || B
00100
01101
10001
11011

課本運算式範例解析：

• (6==6) && (5>6) ➔ (1 && 0) ➔ 0 (False)

• (6==6) || (5>6) ➔ (1 || 0) ➔ 1 (True)

• !(6!=5) ➔ !(1) ➔ 0 (False)

選擇結構語法與實務 (Selection Statements)

■ if 敘述 (單向選擇)

條件式為 true 時才執行被指定的敘述。若有多行程式碼必須使用花括號 { } 包裹！

if (a == 1) {
    cout << "輸入 1" << endl;
    cout << "1是正數" << endl;
}

⚠️ 注意：萬一忘記加上 {}，則只會執行第一行敘述句！

■ if-else 敘述 (雙向選擇)

條件成立執行 if 區塊，條件不成立則執行 else 區塊。

if (score >= 60)
    cout << "恭喜過關!" << endl;
else
    cout << "未過關!" << endl;

■ if ~ else if ~ else 敘述 (多重選擇 / Else-If Ladder)

用於多個互斥條件判斷，程式會從上到下依次檢查條件，一旦某條件成立便執行對應區塊並跳出。

if (g >= 90)
    cout << "等級A";
else if (g >= 80)
    cout << "等級B";
else if (g >= 70)
    cout << "等級C";
else
    cout << "等級D";

■ 三元運算子 (條件運算子 ?:)

語法：條件式 ? true時執行 : false時執行;

1. 求兩數最大值 max 
max = (a > b) ? a : b;
2. 求 a 的絕對值 ab 
ab = (a > 0) ? a : -a;
3. 判斷奇偶數 odd 
odd = (n % 2) ? 1 : 0;

■ 巢狀 if 實例 (車速判斷)

if (vel > 60) {
    if (vel < 100) {
        cout << "標準車速!";
    } else {
        cout << "車速太快!";
    }
} else {
    cout << "車速太慢!";
}

■ switch 敘述 (多重選擇)

switch(res) {
    case 1:
        cout << "輸入的是1。" << endl;
        break;
    case 2:
        cout << "輸入的是2。" << endl;
        break;
    default:
        cout << "請輸入1或2" << endl;
        break;
}

• 常數值可為單一常數 (如 1, 'A') 或連續常數 (如 1...3)。

• break 用於強制跳出，未加會繼續向下執行 (Fall-through)。

<補充資料> 格式化輸出 (<iomanip>)

透過引入 <iomanip>，可以使用 setw() 設定欄寬，以及 setfill() 設定填補字元。

#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int A = 10;
    cout << A << endl;                          // 10
    cout << setw(4) << A << endl;                 //   10
    cout << setw(4) << setfill('0') << A << endl; // 0010
    cout << setw(4) << setfill('_') << A << endl; // __10
    return 0;
}
