4.3

關係運算子

用來比較兩個運算式的大小關係，結果只有兩種：成立為 true（1），不成立為 false（0）。

先自己想結果是什麼，再點右欄的「?」檢查。

不要弄錯 =（指定運算子）和 ==（關係運算子）。a = 6 是把 6 放進 a；a == 6 才是比較。

把 == 寫成 = 會怎樣？

a == 6 的結果會隨變數 a 的值改變。若寫成 a = 6，a 會先被改成 6，而運算式的值是 6（非 0 即為 true），所以不論 a 原本是多少，條件都成立。

4.5

if 敘述

if (條件式)
    其他敘述句;

if (條件式) {        // 2 行以上要加大括號
    程式敘述句1;
    程式敘述句2;
}

唯有當條件式為 true 時，才會執行被指定的敘述。

萬一忘記加上 { }，if 只管到下一行敘述，之後的敘述就不屬於 if。縮排只是給人看的，編譯器不看縮排。

試試 a = 5：沒有大括號時，「1 是正數」還是會印出來。

4.6

if～else 敘述

if (條件式)
    程式敘述1;
else
    程式敘述2;

條件式不成立時，便會執行 else 之後的敘述句。兩條路一定會走其中一條，也只會走一條。

72

大括號搭配 else

if 的部分有兩行，所以用 { } 包起來；else 只有一行，可以不加。

4.7

三元運算子（條件運算子）

條件式 ? true 的時候 : false 的時候

可以把簡單的 if～else 濃縮成一行：

if (a > b)
    max = a;
else
    max = b;
// ↓ 等同於
max = (a > b) ? a : b;

4.10

switch 敘述

  • 括號內運算式的值與某個 case 後面的值一致，就從該 case 開始執行，直到碰上 break 為止。
  • 沒有任何相符的 case，就跳到 default: 執行。
  • case 後面的常數值可以是單一常數，例如 1 或 'A'；GCC 也接受連續範圍，例如 case 1 ... 3:、case 'A' ... 'C':。
  • break 會強制中斷執行流程，位置放錯就會影響結果。勾選下面的選項看看。
res =

刪掉 break 後選 res = 1：程式會「穿越」到 case 2 繼續執行，印出兩行。

格式化輸出：setw 與 setfill

要先 #include <iomanip>。setw(n) 設定下一個輸出項目至少佔 n 格，不足的部分從左邊補上 setfill 指定的字元（預設是空白）。

int A = 10;
cout << A << endl;
cout << setw(4) << A << endl;
cout << setw(4) << setfill('0') << A << endl;
cout << setw(4) << setfill('_') << A << endl;

__10

注意：setw 只影響下一個輸出；setfill 設定後會一直有效，直到再次更改。
