1.1

程式語言簡介

程式語言主要是用來和電腦溝通，讓電腦幫助我們完成想做的事情。依照和人類語言的接近程度，分成兩大類：

種類例子特色
低階語言機器語言、組合語言接近電腦的語言，人類難讀，執行快
高階語言C/C++、Pascal、Java、Cobol、Python、Visual Basic接近人類的語言，容易讀寫，需要翻譯成機器語言

右邊是同一件事「a = b + c」在三個層級的寫法（組合語言與機器碼為示意）。

高階語言C++
a = b + c;
組合語言低階・用英文縮寫代表指令
mov  eax, [b]    ; 把 b 搬進暫存器
add  eax, [c]    ; 加上 c
mov  [a], eax    ; 結果存回 a
機器語言低階・電腦唯一看得懂的 0 與 1
10001011 01000101 11111000
00000011 01000101 11110100
10001001 01000101 11111100

編譯式與直譯式語言

C/C++、Python 等是人類較易理解的高階語言，要透過編譯器或直譯器轉換成電腦能理解的機器語言。差別在於「一次全部翻譯」還是「一行一行邊翻邊做」。

直譯式語言 例：Python

編譯式語言 例：C/C++

        

          原始程式碼檔→編譯→目的碼檔→連結 ＋ 函數庫→可執行檔

1.4
程式設計常見問題

  

    

      
語法錯誤（syntax error）

      
違反程式語言的語法規則，會產生編譯錯誤或連結錯誤。編譯器會告訴你錯在哪一行。

      
cout << "Hello" << endl    // 少掉分號 ;

      
到模擬器試試 →

    

    

      
語意錯誤（semantic error）或邏輯錯誤（logic error）

      
語法完全正確，可以編譯，但執行時產生意外的輸出或與預期不符的結果。編譯器抓不到。

      
a = b / c;    // 語法正確，但若 c 為 0，執行時會出錯
