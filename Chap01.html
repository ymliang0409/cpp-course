第一章 程式語言簡介

程式語言是人類與電腦溝通的橋樑。本章將帶您瞭解程式語言的分類、編譯與直譯的差異，以及寫出您的第一個 C++ 程式。

程式語言的分類

低階語言 (Low-Level)

貼近電腦硬體的語言，執行效率極高，但人類較難直接閱讀與維護。

  • 機器語言： 由 0 與 1 組成的二進位碼
  • 組合語言： 使用簡單符號（助記碼）代表指令

高階語言 (High-Level)

語法接近人類語言（英文）與數學符號，易於學習、撰寫與維護。

C / C++ Python Java Visual Basic

直譯式 vs 編譯式語言

Python 等

直譯式語言 (Interpreter)

邊翻譯邊執行，不需預先轉換成可執行檔。

原始碼 (.py) 直譯器 機器指令並執行
C / C++ 等

編譯式語言 (Compiler)

整份程式碼預先編譯成機器碼檔，再連結函式庫產生獨立執行檔。

原始碼 (.cpp) 編譯 (.o) 連結 (函式庫) 執行檔 (.exe)

C++ 程式設計開發流程

1. 分析與撰寫 繪製流程圖並撰寫 .cpp 原始碼
2. 編譯過程 檢查語法，生成 .o 目的碼
3. 連結程序 結合函式庫生成 .exe 執行檔
4. 執行與測試 執行程式並進行除錯 (Debug)

程式設計常見錯誤類型

語法錯誤 (Syntax Error)

違反程式語言的文法規定（如漏寫分號、括號不對稱）。

編譯階段發現 (Compile Error)

連結錯誤 (Link Error)

找不到函式庫或未定義的主函式 main()。

連結階段發現 (Link Error)

執行/邏輯錯誤 (Runtime Error)

除以零、陣列越界，或是邏輯不符預期。

執行階段發生 (Runtime Error)
